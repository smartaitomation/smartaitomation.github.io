WEEK 1 · AI fundamentals & build an agent
- Understand tokens, context limits, model behavior and structured outputs.
- Build an agent loop with tool calls, stop conditions and bounded retries.
- Define allowed actions, permissions, clarification and human escalation.
- Record messages, tool inputs and outputs; learn why final answers alone are not enough to evaluate an agent.
Lab: Build a working agent and inspect its first complete trace.

WEEK 2 · Error analysis
- Build a trace viewer and review examples with a domain expert.
- Label Good/Bad with a specific reason and the step where the error happened.
- Cluster review notes into error types and prioritize by frequency and impact.
- Define one pass/fail check per error; use code for objective rules and judges where interpretation is needed.
Lab: Review a varied set of traces, create an error taxonomy and write the rules your evals will check.

WEEK 3 · Create synthetic evaluation data
- Generate cases from features, roles and scenarios, including ambiguity, missing data and multi-step requests.
- Review synthetic questions, expected behavior and source evidence with a domain expert.
- Separate train, dev and test cases; check coverage by error type and category.
- Calibrate LLM judges against expert labels using false positives, false negatives, precision and recall.
Lab: Build a versioned evaluation dataset and test whether your judge catches the mistakes an expert sees.

WEEK 4 · Improve your AI agent
- Use the error clusters to decide whether to change data, retrieval, prompts, models or tool flow.
- Try better examples, clearer instructions, query rewriting, routing or smaller task scopes.
- Compare changes on the same cases. Measure fixes, regressions, cost and latency.
- Test prompt injection, permissions and unsafe actions; automate evals in CI and monitor production drift.
Lab: Run a before/after experiment and explain what improved, what regressed and what to try next.
