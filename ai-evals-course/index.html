AI Evals for Engineers & PMs

Course syllabus · Instructor: Ion Moșnoi

A hands-on course on evaluating and improving AI products. Build a working agent, capture its behavior in traces, find its failures with a domain expert, and use evaluations to improve accuracy, cost and reliability.

Four weeks, with four live Saturday lectures, 10:00–12:00 Europe/Chișinău (UTC+2), plus 10+ hours of optional live office hours. Teaching is in English. Each module combines a lecture with a practical lab.

Module 1 — Building agents (Week 1)

Create the agent and traces that the rest of the course will use.

L1: AI fundamentals and the agent loop. Understand tokens, context limits, model behavior and structured outputs. Build a loop with tool calls, stop conditions and bounded retries.

Scope and permissions. Define allowed actions, when to ask for clarification and when to escalate to a human. Enforce permissions in code.

Make behavior visible. Record messages, model calls, tool inputs and outputs. Learn why a plausible final answer can hide a failed action.

Lab. Build a working agent and inspect its first complete trace.

Module 2 — Error analysis (Week 2)

Turn real failures into an error taxonomy and clear evaluation rules.

L2: Review with a domain expert. Build a trace viewer. Review varied examples, label Good or Bad, and note the exact step, evidence and expected behavior.

Find patterns. Cluster review notes into error types. Check category counts and prioritize failures by frequency and impact; an overall average can hide a broken feature.

One evaluator per failure mode. Write pass/fail criteria. Use code for objective checks and an LLM judge only when interpretation is needed.

Lab. Review traces, create an error taxonomy and write the rules your evals will check.

Module 3 — Evaluation data & judges (Week 3)

Build a useful test set and check whether the judge can be trusted.

L3: Create synthetic evaluation data. Combine features, roles and scenarios. Include ambiguous requests, missing information and multi-step tasks. Review questions, expected behavior and source evidence with an expert.

Separate development from testing. Version datasets, check category coverage and keep train, dev and test cases separate. Hold test cases aside while tuning prompts.

Calibrate the judge. Write judge prompts with clear rules and diverse examples. Compare judgments with expert labels, inspect false positives and false negatives, and report precision and recall by error type.

Lab. Create a versioned dataset and improve a judge using its disagreements with the expert.

Module 4 — Improve your agent (Week 4)

Use the failures to choose a fix, then measure what changed.

L4: Diagnose and experiment. Decide whether the problem is in data, retrieval, prompts, the model or tool flow. Try clearer instructions, better examples, query rewriting, routing or smaller task scopes.

Measure fixes and regressions. Compare versions on the same cases. Track failures by category alongside accuracy, cost and latency. Keep changes supported by the evidence.

Keep checking in production. Test prompt injection, permissions and unsafe actions. Automate regression checks in CI and monitor new failures and drift.

Lab. Run a before/after experiment and explain what improved, what regressed and what to try next.

A FEW PRACTICAL DETAILS

Before you join.

When does the course run?+

Choose 21 November–18 December 2026 (€500) or 19 December 2026–15 January 2027 (€1,000). Both run for four weeks. Lectures are on Saturdays, 10:00–12:00 Europe/Chișinău (UTC+2). November lecture dates: 21 & 28 Nov, 5 & 12 Dec. December lecture dates: 19 & 26 Dec, 2 & 9 Jan. Office-hour times will be arranged separately.

How much time should I set aside?+

Plan around 3–5 hours weekly for live sessions and independent practice. Optional office hours add 10+ hours across the course. The assignments include solutions and recorded walkthroughs.

What does lifetime access include?+

Keep access to the course recordings, materials and private Discord community. You may also join future live editions of this course without another course fee; register with Ion before each cohort. See the course terms for scope.

What if I cannot attend live?+

Course sessions are recorded, with lifetime access. Use Discord for questions and join office hours when you can. Meeting links and recordings are provided to enrolled participants.

Do I need to be an engineer?+

Engineers should be comfortable running basic Python. PMs and domain experts can focus on reviews, test cases and release decisions, pairing for coding labs. No ML research background is needed.

Who is this course not for?+

It is not a general introduction to using chatbots, a model-training research course or a promise to ship a complete product in four weeks. You should be ready to inspect examples, write review notes and test changes.

Do I need an existing product or customers?+

No. Start with the supplied materials. Learn how to build synthetic cases from roles, features and scenarios, then use expert review to check them before trusting the labels.

What will I have by the end?+

An inspectable agent, reviewed error taxonomy, versioned evaluation dataset, calibrated evaluators and a before/after improvement report. Your results will depend on your cases and implementation; the goal is a method you can reuse.

Which tools will we use?+

Python, JSON/CSV, a small agent/tool loop, code assertions and model-API calls. Use Codex or Claude to help build interfaces and scripts. The method is framework-independent; any optional model-provider usage is billed by your own provider account and is not included in tuition.

Does this cover agents, RAG and security?+

Yes. Inspect tool calls and retrieval separately from answer quality. Test permissions, prompt injection, unsafe actions and human escalation, then connect checks to CI and production monitoring.

How do I earn the certificate?+

Submit at least four of the six assignments, including the final improvement report. Ion reviews your work before issuing your named certificate. It is a completion certificate, not an accredited qualification.

Can my company pay or enroll a team?+

Yes. Use the reimbursement email template and the payment confirmation. Book 2–20 seats together for 10% off; reply to the confirmation with participant details. Contact Ion for larger groups or private delivery.

How is this different from learning alone?+

You get a connected practice sequence, expert review, office hours, community discussion and worked solutions. The focus is making your evaluations reliable enough to guide actual engineering decisions.

Is this course affiliated with Maven or an AI provider?+

No. This is an independently developed SmartAItomation course taught by Ion Moșnoi. The listed tools and public references do not imply affiliation or endorsement.
