The curriculum, adapted to your problem

Learn the principles.
Apply them immediately.

The workshop focuses on your bottleneck. These are the available modules, not a promise to master all of AI in two days.

01 Data quality, ML and training principles

Cleaning, deduplication, labeling, representative sampling and data rights. Train/validation/test splits, leakage, imbalance, overfitting, precision/recall tradeoffs and when fine-tuning is justified. Decide when rules or conventional ML are enough.

02 RAG, retrieval and chunking strategies

Parsing and document structure; fixed-size, recursive, semantic and parent–child chunking; overlap and metadata. Compare keyword, vector and hybrid retrieval, reranking, source citations, freshness and permission filtering against your evaluation set.

03 Agents and the harness around them

Choose a workflow or an agent deliberately. Define tool schemas, state, context, timeouts, retries, idempotency, budgets and stopping conditions. Add approval boundaries and tests for prompt injection, tool failures and unauthorized actions.

04 Evaluation datasets, metrics and error analysis

Start with real task examples and an error taxonomy. Use deterministic checks, calibrated model graders and human review. Track task success, retrieval quality, false positives/negatives, latency and cost. Separate a passing fixture from evidence of generalization.

05 Improve AI for a specific task

Compare prompt, model, data and retrieval changes against a fixed baseline. Capture corrections without contaminating the held-out set. Make experiments reproducible and set release gates before changing production behavior.

06 Coding with AI and operating the result

Write useful task briefs, repository instructions and testable acceptance criteria. Review AI-generated code, protect secrets and verify dependencies. Add regression tests, traces, redacted logs, alerts, cost visibility, rollout and rollback procedures.

Before you book

Practical questions.

Is $10,000 per person?

No. It is the fee for one tailored team engagement. Team size, live hours and the 1–2 day format are agreed in the proposal so there is enough hands-on attention.

Can this work for an enterprise team?

Yes, within an agreed team and use case. We review data access, approved tools, security review and procurement requirements during scoping. Enterprise-wide rollout or compliance certification is outside the workshop.

Do we need a prototype?

A prototype helps, but a clear task and representative data can be enough. The fit check identifies missing prerequisites before we book the workshop.
