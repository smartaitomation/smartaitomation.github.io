Record yarn dye lots so project substitutions remain clear

By Smart Automation SRLOctober 12, 20266 min read

Record the yarn brand, line, color code and dye lot separately, then link each physical ball to the project using it. A matching color name does not establish a matching dye lot. Keep an unclear label marked unknown and compare the actual yarn before approving a substitute; an inventory entry cannot guarantee how two yarns will look together.

Copy the label before discarding it

The Craft Yarn Council identifies brand, fiber, color name/number, dye lot or no-dye-lot wording, length, quantity and gauge information as useful label details. Photograph or retain the label so you can check a transcription later. Give the ball or group of genuinely matching labeled balls a local ID.

Do not store “blue” as the whole identity. Two lines from one manufacturer can share a color description while differing in fiber, size or length. Preserve the exact line and code. Copy the dye-lot string as text, including leading zeros or letters; a spreadsheet may otherwise turn an identifier into a number and remove useful characters. In the import dialog, set color_code and dye_lot_text to Text before completing import. Verify the saved sheet still shows 017 and 0042; opening the CSV with default settings may remove zeros.

Record “no dye lot” only when the label says so. “Label missing” is a different state. If a partially used ball has lost its band, keep its provenance uncertain rather than assigning the lot of the nearest ball. Quantity should state its unit and whether measured or estimated; an estimated partial-ball amount is not a verified project supply.

Check the actual yarn and preserve the decision

Lion Brand explains that colors from different lots can appear similar under one light and different under another, and its support page does not promise matching old lots when ordering more. Compare the physical candidate with retained yarn in natural and artificial light where practical. Photos help keep evidence but cannot establish an exact color match across displays.

For a changed brand, line or weight, use the project’s gauge and care requirements and make the appropriate sample before committing. The Craft Yarn Council recommends checking gauge when substituting brands. A matching weight category alone is not a guarantee of the same finished size or appearance.

Write a dated decision: “candidate not used,” “sample still needed,” or “accepted for this project after checking.” Retain the old and new identifiers even after acceptance. If you later notice a visible difference, you can identify which ball entered the work. Avoid rewriting every ball as one lot merely because you decided the difference was acceptable.

Questions answered

Is a color code the same as a dye lot?

No. Preserve both separately; the same color code can appear on different lot labels.

What do I enter for a missing ball band?

Mark the source and lot unknown. Do not copy another ball’s lot without evidence.

Can a label photo prove two yarns match?

It helps verify the identifier, but compare physical yarn and relevant project requirements before deciding.
