Count mic stands and DI channels from the confirmed input plan

By Smart Automation SRLOctober 30, 20267 min read

Start from explicit audio sources and agreed capture methods, then count the required equipment and who will provide it. Input channels, DI channels, DI enclosures and mic stands are different units. “House supplied” is a request until the venue confirms it.

Count a capture plan, not instrument icons

An instrument symbol on a stage diagram does not tell you how it reaches the mixer. Write the source, channel allocation, agreed mic/DI method, required stand type and provider. Use the stage plot/input-list guide to establish that shared reference before packing.

Yamaha’s sound-check guidance describes the input list and stage plot as complementary documents and recommends matching source identifiers. That supports tracing a packing requirement back to a source; it does not prescribe one stand or DI for every instrument. The actual connection and safe equipment setup must be agreed with the relevant crew.

Keep mic stands separate from music stands. A handheld mic, a clip-mounted mic and a mic on a boom have different support plans. Record an unspecified support as an open question, not zero. If one stand is deliberately shared across mutually exclusive tasks, document that condition rather than counting it twice.

Four channels, two stands and two DI channels

This fictional setup is explicitly agreed for the example: vocal input 1 uses one boom stand; guitar-amp mic input 2 uses one short stand; keyboard left/right inputs 3–4 use two DI channels and no mic stands. It is not a universal recommendation for connecting keyboards or amplifiers.

Required minus confirmed venue provision equals the bring requirement only when the units and compatibility match. “Venue asked” must not be subtracted as though it were confirmed.

Two DI channels do not necessarily mean two physical boxes. A suitable two-channel enclosure can provide two channels; a one-channel unit provides one. Record the actual unit/channel allocation and agree compatibility rather than counting only enclosures. The band’s remaining DI is still not packed until someone checks it.

Separate a confirmed provider from a packed item

Use a specific source of confirmation and date for venue provision. If a reply says only “we have DIs,” ask whether the required quantity, channels and suitable configuration are available for this show. Do not mark all requirements satisfied from a generic equipment inventory.

Before departure, count the actual band case contents against the bring column. A shopping or rental order is not a packed item, and a packed case is not proof that the unit works. Verify the relevant condition and setup through the crew’s normal process. This worksheet does not certify electrical safety, phantom-power suitability or cable compatibility.

When an input is removed or changed, update the plot, patch and packing list together. Keep the revision reference visible so a venue does not prepare from an older version. If the separate next task is monitor requests, use the monitor mix request guide; a wedge count is not a count of independent mixes.

Questions answered

Does a stereo source require two mic stands?

No. Channel count alone does not determine supports. The worked keyboard plan uses two DI channels and no mic stands; other real setups need their own agreed plan.

Are two DI channels always two boxes?

No. Record the actual enclosure and channel capacity plus compatibility. Do not silently mix channel and box units.

Can I count a requested house stand as confirmed?

No. Keep requested, confirmed and physically packed states separate until the relevant evidence exists.
