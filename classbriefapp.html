ClassBrief

Create a local day plan, record completed periods, and share the current anonymous return brief as plain text.

How ClassBrief works

1. Build the dayChoose a schedule structure and edit each period’s title, time or sequence, and optional objective.
2. Record an outcomeFor the current period, choose class-level observation labels, add an optional anonymous note, and tap Mark complete.
3. Review the briefThe return brief shows the completed-period outcomes currently recorded by the app.
4. Hand it backShare the current anonymous return brief as plain text using the destinations you choose in iOS.

No student records

ClassBrief is for teacher-owned plans and class-level handoff notes. Do not enter student names, contact details, grades, disability information, protected traits, accounts, photos, or behavior profiles. The app applies an on-device text check before local persistence or plain-text sharing of suspected identifying or protected-record content.

Troubleshooting

The app says OfflineClassBrief’s planning, outcome, and brief screens do not call a developer backend. A destination selected from the iOS share sheet may still require its own network connection.
Text was blockedRemove possible identifying or protected student information, then retry. The correctable draft remains visible and is not saved or exported while blocked.
PDF says unavailableUse Share plain text instead. The current Release build cannot unlock or generate the Premium PDF.

Current build availability

Subscriptions, Restore Purchases, entitlement-based Premium unlocking, PDF generation, and reminder scheduling are not available in the current Release build. ClassBrief currently provides its local plan-to-brief workflow and plain-text sharing without a purchase.
