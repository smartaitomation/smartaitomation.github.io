Tropic Tray support

Quick answers for the installable web game. The PWA has no account or cloud save, so you can keep playing without signing in.

Game not responding?

Reload once. Your current run is saved in this browser after each move.

Want to install it?

Use “Install game” on the play screen, or your browser’s Add to Home Screen command.

Progress disappeared?

Progress is device-local. Clearing browser site data, using private browsing, or switching devices starts a new tray.

Shop question?

The web shop is only a preview. It cannot accept payments, grant paid coins, or unlock VIP.

Gameplay basics

Drop the current drink into one of five lanes. Equal drinks that touch at the top combine. Create the drink shown on the beach order to earn coins and clear space. If any lane reaches six drinks, the run ends.

Keyboard controls

Use Left and Right Arrow to select a lane, Enter or Space to drop, number keys 1–5 to quick-drop, and U to undo.

Need another route?

Return to the game, review privacy, or read the terms.
